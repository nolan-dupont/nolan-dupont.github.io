Description

Ce projet a eu pour objectif de réaliser un algorithme de tri automatique de dépêches de presse, accompagné d'un autre étudiant. Le programme est écrit en Java et utilise un algorithme d'apprentissage automatique afin de former un dictionnaire associant un sujet à chaque mot. Une fois entraîné, le programme est capable de catégoriser avec une certaine précision des dépêches dans la catégorie la plus proche.
