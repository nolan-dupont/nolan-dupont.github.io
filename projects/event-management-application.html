Description

Dans le cadre de ce projet, nous avons développé par groupe de 5 personnes une application de gestion d'évènement. Le thème de l'application était libre, nous avons décidé de créer un application à destination des propriétaires de salons de jeux de sociétés.
Cette application permet de gérer le matériel, les membres, les employés, les commandes et planning d'une petite entreprise.

Produit final

Un image du produit final est disponible dans la galerie (voir Figure 2 ). Il s'agit de la vue de l'application du gérant du salon de jeu. Il a accès à toutes les fonctionnalités de l'application, tandis que les gestionnaires n'ont pas accès au planning, et les animateurs n'ont accès qu'au planning.

Détails techniques

Ce projet a utilisé la bibliothèque d'interface graphique JavaFX, il a reçu une semaine de cadrage de projet, suivi immédiatement d'une semaine de développement. Aucune de base de données relationnelle n'a été utilisée, à la place nous avons utilisé la sérialisation de classes Java pour enregistrer l'état de l'application.

Rôle

Mon rôle a été dans un premier temps de participer à la phase cadrage de projet, durant laquelle nous avons créé un document de conception, pris en compte les contraintes du projet, choisi un logo et avons fait des diagrammes UML. Parmi ces diagrammes UML, nous avons réalisé un diagramme de classe.
