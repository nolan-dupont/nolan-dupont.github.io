Description

Ce projet a eu pour objectif de réaliser un manuel détaillant l'installation de Debian 12 sans interface graphique sur une machine virtuelle, et la mise en place d'un serveur Apache, un serveur PostgreSQL ainsi que PHP afin de faire tourner un site web. Le manuel a été rédigé en utilisant le langage LaTeX.
